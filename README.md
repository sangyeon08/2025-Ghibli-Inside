# 2025 Ghibli Inside

2025 MSG 2학년 IT쇼 프로젝트

## 소개

**2025 Ghibli Inside**는 Studio Ghibli의 작품과 관련된 캐릭터를 토대로 진행하는 성격 유형 테스트 웹사이트입니다. 본 프로젝트는 IT쇼 참가를 위해 MSG 2학년 팀이 개발하였습니다.

## 주요 기능

- 지브리 작품 정보 조회 및 소개
- 직관적이고 아름다운 웹 인터페이스
- 사용자 친화적 네비게이션
- 반응형 디자인 적용

## 사용 기술

- **CSS** (46.1%)  
- **Hack** (23.9%)
- **PHP** (16.4%)
- **HTML** (13.6%)

## 프로젝트 구조(주요 파일)

프로젝트의 주요 폴더 및 파일은 다음과 같습니다:

- `index.html` : 메인 페이지
- `style.css` : 전역 스타일 정의
- `ghibli.php` : PHP 기반 서버 로직 처리
- `assets/` : 이미지, 아이콘 등 정적 리소스
- 기타 Hack 언어 파일 : 동적 기능 및 백엔드 구현 담당

> 상세한 파일 구조 및 각 파일의 목적은 코드 내 주석을 참고해 주세요.

## 설치 및 실행 방법

1. 본 레포지토리를 클론합니다.
   ```bash
   git clone https://github.com/sangyeon08/2025-Ghibli-Inside.git
   ```
2. 웹 서버(Apache, Nginx 등)를 이용해 프로젝트 폴더를 서빙합니다.
3. 웹 브라우저에서 index.html 또는 해당 PHP 파일에 접근합니다.

## 기여 방법

1. 이슈 생성 또는 포크 후 풀 리퀘스트 제출
2. 코드 작성 시 [커밋 메시지 가이드라인]을 준수해 주세요.
